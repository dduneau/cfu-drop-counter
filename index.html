          What the layout file looks like
          
One row per fly, with an ID and where the fly sits. ROW puts the fly on every well of that row (dilution series across the columns), COL on every well of that column, WELL on one well. Every other column is copied into the result.

          
ROW;ID;Sex;Line;Age_at_infection
A;F001;Female;CantonS;10
B;F002;Male;CantonS;10

          
Add a Plate column when different plates hold different flies. Without it, the same flies sit in the same wells on every plate.

          
Plate;ROW;ID;Sex
plate01;A;F001;Female
plate02;A;F009;Female
